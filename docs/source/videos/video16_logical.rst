Vidéo 16 : Comment utiliser les opérateurs logiques dans les programmes Arduino
=======================================================================================

Cette leçon explique comment les opérateurs logiques sont utilisés pour combiner des conditions dans les programmes Arduino.

* **Opérateurs logiques :** Présente AND (&&), OR (||) et NOT (!).
* **Combinaison de conditions :** Montre comment plusieurs conditions sont évaluées ensemble.
* **Logique de contrôle :** Montre l’utilisation d’expressions logiques dans les instructions de décision.
* **Exemples pratiques :** Applique les opérateurs logiques dans des sketches simples.
