Vidéo 2 : Composants et outils pour le maker Arduino
======================================================

Cette leçon présente les outils courants et les composants électroniques utilisés avec Arduino.

* **Types de cartes Arduino :** Présente Uno, Nano et Mega, et explique pourquoi Uno est utilisé dans ce cours.
* **Structure de la plaque d’essai (breadboard) :** Explique les connexions internes des rangées, les rails d’alimentation et l’espace central pour les circuits intégrés.
* **Fils de connexion (jumpers) :** Présente les différents types de fils de connexion et leurs utilisations typiques.
* **Composants courants :** Couvre les pièces de base telles que les résistances, les condensateurs, les LED, les boutons, les potentiomètres, les écrans et les capteurs.
