Vidéo 31 : Comment utiliser des photo-résistances
==========================================================

Cette leçon explique comment les photo-résistances sont utilisées pour détecter les niveaux de lumière avec Arduino.

* **Comportement de la photo-résistance :** Explique comment la résistance change en fonction de l’intensité lumineuse.
* **Diviseur de tension :** Montre comment convertir les variations de résistance en tension.
* **Lecture analogique :** Montre comment les niveaux de lumière sont lus via des entrées analogiques.
* **Détection de seuil :** Montre comment réagir aux changements du niveau de lumière.
