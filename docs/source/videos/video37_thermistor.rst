Video 37: How to Use Temperature Sensors
==========================================================

This lesson introduces temperature sensors and explains how their output is read by Arduino.

* **Temperature sensing:** Explains how temperature sensors detect heat changes.
* **Sensor modules:** Introduces common temperature sensor types.
* **Data reading:** Demonstrates converting sensor output to temperature values.
* **Signal interpretation:** Explains interpreting temperature readings.
