Vidéo 5 : Comment utiliser la modulation de largeur d’impulsion (PWM)
==============================================================================

Cette leçon explique comment fonctionne la modulation de largeur d’impulsion (PWM) sur Arduino.

* **Concept du PWM :** Explique le rapport cyclique et la synchronisation du signal.
* **Broches PWM :** Identifie les broches Arduino qui prennent en charge le PWM.
* **Sortie de type analogique :** Montre comment contrôler les niveaux de sortie à l’aide du PWM.
* **Luminosité des LED :** Montre comment le PWM est utilisé pour faire varier la luminosité des LED.
