Video 6: Cómo usar potenciómetros
======================================================

* **Entrada analógica:** Demuestra cómo leer valores del potenciómetro con Arduino.
* **Configuración del cableado:** Muestra cómo conectar correctamente un potenciómetro.
* **Mapeo de valores:** Demuestra cómo usar valores analógicos para controlar la salida.
