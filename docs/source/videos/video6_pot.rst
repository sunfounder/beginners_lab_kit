Video 6: How to Use Potentiometers
======================================================

This lesson introduces potentiometers as variable analog input devices.

* **Potentiometer operation:** Explains how changing resistance affects voltage.
* **Analog input:** Demonstrates reading potentiometer values with Arduino.
* **Wiring setup:** Shows how to connect a potentiometer correctly.
* **Value mapping:** Demonstrates using analog values to control output.
