Vidéo 7 : Comment utiliser des boutons-poussoirs
======================================================

Cette leçon explique comment les boutons-poussoirs sont utilisés comme entrées numériques.

* **Fonctionnement des boutons :** Explique comment les boutons-poussoirs ouvrent et ferment les circuits.
* **Câblage des boutons :** Montre le câblage correct pour les entrées de boutons.
* **États d’entrée :** Montre comment Arduino lit les signaux HIGH et LOW.
* **Contrôle par bouton :** Montre comment déclencher des actions avec des appuis sur les boutons.
